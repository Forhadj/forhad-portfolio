GitHub-powered Control Panel

Token is stored only in this browser's localStorage.
It is never sent anywhere except api.github.com

How to create a token?

1. GitHub → Settings → Developer settings
2. Personal access tokens → Fine-grained tokens
3. Generate new token
4. Repository access: Only select repositories → your portfolio repo
5. Permissions → Repository permissions → Contents: Read and write
6. Copy the github_pat_... or ghp_... token here
